# Mind Matrix 80

Mind Matrix 80 is an Android application designed to provide an intelligent and interactive user experience using modern Android development technologies.

---

## 🚀 Features

- User-friendly interface
- Firebase integration
- Secure authentication system
- Real-time database support
- Modern Android UI with Jetpack Compose
- Fast and responsive performance

---

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Firebase Authentication
- Cloud Firestore
- Material Design

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/abhishekijeri31-cloud/mind-matrix-80.git
```

### 2. Open the project in Android Studio

### 3. Sync Gradle files

### 4. Add Firebase configuration file

Place the following file inside the `app/` folder:

```bash
google-services.json
```

### 5. Run the application

Run the app on an emulator or Android device.

---

## 🔥 Firebase Setup

This project uses Firebase services.

Steps:

1. Create a Firebase project
2. Enable Firebase Authentication
3. Enable Cloud Firestore
4. Download `google-services.json`
5. Place it inside the `app/` folder
